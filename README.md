# SCT_DA_4
**SkillCraft Technology Data Analytics Internship - Task 4 (Final Task)**

## Project Objective
Perform Exploratory Data Analysis (EDA) on a digital marketing campaign dataset to visualize the customer conversion funnel and identify the most profitable marketing channels based on Return on Investment (ROI).

## Tools Used
* **Language:** Python
* **Libraries:** Pandas (Data manipulation), Matplotlib (Visualization)
* **Environment:** Jupyter Notebook

## Key Business Insights
1. **The Funnel Drop-off:** Visualized the customer journey (Impressions ➡️ Clicks ➡️ Leads ➡️ Conversions) using a logarithmic scale, revealing a massive drop-off between ad impressions and actual clicks. This indicates a need for better ad copy/creative to improve CTR (Click-Through Rate).
2. **ROI Analysis:** Grouped and analyzed 10,000 individual campaigns by marketing channel. 
3. **Strategic Recommendation:** **Search Marketing** yielded the highest overall ROI (101.31%), while **Social Marketing** yielded the lowest (97.66%). The strategic recommendation is to reallocate ad spend away from underperforming social campaigns and inject it into high-intent search campaigns.
